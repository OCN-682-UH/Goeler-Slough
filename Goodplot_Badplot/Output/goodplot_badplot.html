This dataset contains information on non-fire incidents (also called ‘special services’) that the London Fire Brigade has attended to, for a variety of animal rescue endeavors. It is a tidytuesday dataset, that comes from London.gov by way of Data is Plural and Georgios Karamanis. It contains data on 7544 total animal rescues, from years 2009 through 2021, with responses to 28 types of animals.

This plot is bad for many reasons:

  • The plotting icons (dogs and cats) are misleading because they’re representing other types of animals that were rescued (for example, cat rescues are plotted with a husky dog icon, and dog rescues are plotted with a toast cat icon). (Goes against principles in Wilke mapping data onto visual features)
  • The legend icons are tiny and make it hard to determine which icon is being plotted to which animal
  • The plotted icons are overlapping so much that you can’t visualize what’s happening, especially at the lower cost values. (Goes against principles in mapping data onto visual features, with overplotting that conceals data distribution.)
  • The transitions are quite fast and make it hard to see what’s going on, and the transition animation bouncing only makes it harder to visualize/interpret
  • Cost (on the x-axis) isn’t defined / the units aren’t specified, making it unclear what exactly is being plotted. Additionally, all the cost numbers are flipped upside down, making it even more annoying to read
  • The neon background colors add to the visual overstimulation (what Wilke would probably call an “ugly” plot, breaking principles of using color to encode meaningful variables)
  • Longitude and latitude aren’t plotted against each other as would make sense; the size of the icon is the only place you can visualize longitude
  • Even if you had latitude and longitude on each axis, these would be plotted without context; these are somewhat meaningless without a reference frame. Most people probably wouldn’t even be able to tell these data are from London! (Not following standards for mapping onto coordinate systems.)
  • No figure caption, descriptive title, or subtitle describing what’s going on in this plot; it would be very hard to interpret this figure as a standalone without any additional text description

2. Good Plot:

Cleaning data / data wrangling

Show code 
#cleaning data
rescues_clean <- animal_rescues %>%
  mutate(
    longitude = as.numeric(longitude),
    latitude = as.numeric(latitude),
    incident_notional_cost = as.numeric(incident_notional_cost)) %>%
  drop_na(latitude, longitude, incident_notional_cost, animal_group_parent) %>%
  filter(!animal_group_parent %in% c( #filtering out some unknown categories with only a few instances
    "Unknown - Domestic Animal Or Pet",
    "Unknown - Animal rescue from water - Farm animal",
    "Unknown - Animal rescue from below ground - Farm animal",
    "cat")) %>%
  filter(final_description != "Redacted") %>%
  #arrange(desc(animal_group_parent %in% c("Cat", "Dog", "Bird"))) %>% #putting cats and dogs on the bottom for mapping
  mutate(animal_color_group = as.character(
      fct_lump_min(animal_group_parent, min = 5, other_level = "Other"))) %>% #adding new column for animal coloring where animals with less than 5 instances are labeled as "other"
  mutate(animal_color_group = str_replace(animal_color_group, "Unknown - Wild Animal", " Unknown Wild Animal")) %>%
  mutate(animal_color_group = str_replace(animal_color_group, "Unknown - Heavy Livestock Animal", "Unknown Heavy Livestock"))%>%
  mutate(animal_color_group = fct_infreq(animal_color_group) %>% #re-ordering animal group by abundance
           fct_relevel("Other", after = Inf)) #putting 'other' group at the very end

Creating map of animal rescues attended by the London Fire Brigade:

  • Using {leaflet} to create map, with “Stadia Alidade Smooth” basemap
  • Plotting animal rescues, sizing by cost of rescue and mapping the type of animal by color
  • Making interactive plot to click to see year, animal, notional cost of the rescue, and a brief rescue description
  • Adding layers for each animal to be able to toggle animal types on and off (e.g. to get rid of overwhelmingly abundant animals and/or investigate rarer animals)
Show code 
#setting up map
map <-  leaflet(width = "100%", height = "90vh") |> #making map nice and large
  addProviderTiles(providers$Stadia.AlidadeSmooth) |>
  setView(lng = -0.2, lat = 51.48, zoom = 10) 
#mapping a layer (of circle markers) for each animal
animal_list <- (unique(rescues_clean$animal_group_parent)) #creating list of all animals in this dataset
for (animal in animal_list) {
  sub_df <- rescues_clean |> filter(animal_group_parent == animal) #looping over each animal type so I can add them as separate layers to be able to toggle
  map <- map |>
  addCircleMarkers(
    data = sub_df, #using the dataframe separated by each animal type to make each a layer
    lng = ~longitude, lat = ~latitude,
    color = ~pal(animal_color_group),
    radius = ~(incident_notional_cost)^1.1 * .004, #scaled to visualize on map
    fillOpacity = .45,
    opacity = .6,
    group = animal, #grouping by animal so each layer is one animal
    popup = ~paste0("Year: ", cal_year,  #click a point to see the year of that animal rescue
                   "<br>Animal: ", animal_group_parent, #animal 
                   "<br>Cost: £", format(incident_notional_cost, big.mark = ","), #the notional (estimated) cost of the rescue, adding comma to values in the thousands
                   "<br>Description: ", final_description)) #description of the rescue
}

#adding layer control feature
map |>
  addLayersControl( #adding a layer control so you can toggle on and off specific animals
    overlayGroups = animal_list,
    options = layersControlOptions(collapsed = TRUE)
  ) |>
  
#adding legends
  addLegend( #adding legend for animal colors 
    pal = pal,
    values = factor(rescues_clean$animal_color_group),
    title = "Animal Type",
    position = "topleft",
    opacity = 0.7
  ) |>
  addLegendSize( #adding legend for sizes
    values = diameters, #using calculated diameters from above, based on scaling factor
    breaks = named_breaks, #breaks by selected mass values above, labeled with actual weight in kg
    baseSize = mean(diameters),
    position = "bottomleft",
    title = "Rescue Cost",
    shape = "circle",
    color = "#333333",
    fillColor = "#333333",
    fillOpacity = 0.35)

This plot is good because:

  • Now these data are actually plotted onto a map, with basemap tiles allowing coordinates to be plotted in recognizeable areas. Interactive zoom feature allows viewers to zoom in and out of set area as much as they want for broader context or specific area investigations.
  • While there is a ton of data plotted here, there are multiple ways in which it’s simplified to still be able to interpret and explore visually:
    • Animals with less than 5 instances/rescues in the dataset are grouped into “Other” for coloring purposes on the map
    • There is a layers toggling feature added so that the viewer can select and un-select certain animal groups to explore more niche animals, get rid of overly abundant animals, etc.
    • Neutral, low-saturation basemap paired with distinct colors for animal categories shows clear contrast against the muted background.
    • Leaflet interactive click popups display specific metadata only when prompted to keep the main display clean but contain more information on demand
