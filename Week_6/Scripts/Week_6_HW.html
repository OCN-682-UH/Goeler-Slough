3. Data analysis:

First, I’m generating density plots to visualize the spread of the body measurements collected across each of the 3 species in this dataset.

Show code 
depth <- penguins |>
  ggplot(aes(x=bill_depth_mm, fill=species))+
  geom_density(
    aes(y = after_stat(count)),
    alpha = 0.5,
    color = NA) + #getting rid of black outlines
  labs(
    x = "Bill Depth (mm)",
    y = "Density",
    fill = "Species") +
  theme_bw()+
  theme(legend.position = "none")

Now, I’m creating a summary table with averages of each body measurement for each of the 3 species in this penguin dataset, and including sample size (n) to see the distribution of sampling effort.

Show code 
penguins |>
  group_by(species) |>
  summarise(
    "Bill Length (mm)" = mean(bill_length_mm, na.rm = TRUE),
    "Bill Depth (mm)" = mean(bill_depth_mm, na.rm = TRUE),
    "Flipper Length (mm)" = mean(flipper_length_mm, na.rm = TRUE),
    "Body Mass (kg)" = (mean(body_mass_g, na.rm = TRUE)/1000),
    "n" = n())|>
  rename(Species = species) |> #making species variable name capitalized for table
  kbl(digits=2, # make it a kable table, rounding to 2 digits
      caption = "Average Body Measurements for Palmer Penguins") |> 
  kable_classic() |> # add a theme, kable classic
  column_spec(5, bold = TRUE, background = "turquoise")

Takeaways:

As shown in Figure 1, body measurements (bill depth, bill length, flipper length, and body mass) vary across species. Mean values across species (with sample size) are summarized in Table 1.

Gentoo penguins have a greater body mass on average when compared to Adelie and Chinstrap species (Table 1), which as illustrated by Figure 1, may be linked to their larger flipper length.
