Adding color, lines, & changing theme:

Show code 
ggplot() +
  geom_polygon(data = world,
               aes(x = long, y = lat,
                   group = group,
                   fill = region), #filling each country/region
               color = "black") + # outlining each country/region
  guides(fill="none") + #gets rid of fill legend
  theme_minimal()

Now changing size of points to reflect sea star count, fixing legend, and changing point color:

Show code
